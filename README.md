# Compu Print (Smart Print Shop Pro)

نظام متكامل واحترافي لمعالجة وطباعة وتجهيز البطاقات والصور الشخصية والمستندات للمطابع ومحلات الطباعة والاستوديوهات.

---

## 🌟 الموديولات الرئيسية (Core Workflows)

### 1. طباعة بطاقات الرقم القومي والهويات (ID Cards Workflow)
- كشف ذكي وتلقائي لحدود البطاقات والزوايا والأبعاد (Edge Detection & Perspective Rectification).
- إزالة الميل والتشوهات تلقائياً (Deskewing).
- تصحيح نسبة العرض إلى الارتفاع وفق المعيار القياسي لبطاقات الهوية (ISO/IEC 7810 ID-1: 85.6 × 53.98 مم).
- تصنيف الوجه والظهر ذكياً مع إمكانية التبديل بنقرة واحدة (Swap Roles).
- توزيع تلقائي واقتصادي على مقاسات ورق A4 مع علامات القص (Cut Marks) وإطارات خفيفة.
- إمكانية التعديل اليدوي التفاعلي للزوايا والدوران.

### 2. استوديو الصور الشخصية والشهادات (Personal Photos Studio)
- تجهيز صور المقاسات الرسمية: 4×6 سم، 3×4 سم، 5×5 سم (Passport / Visa).
- كشف ذكي للوجه وتوسيط الرأس والصدر طبقاً للمعايير الرسمية (Head-to-Chin ratio).
- عزل الخلفية وتغييرها بنقرة واحدة: خلفية بيضاء نقية، زرقاء فاتحة، رمادية، أو الأصلية.
- تصحيح الألوان والسطوع والتباين وتشبع البشرة وحرارة اللون وإزالة الظلال الخفيفة.
- مضاعفة النسخ مع خيارات سريعة: 4، 8 (نصف ورقة A4)، 12، 16 صورة (ورقة A4 كاملة).
- نافذة تعديل يدوي حية وتفاعلية.

### 3. طباعة المستندات العامة والـ PDF (Generic Document Printing)
- دعم كامل لملفات: `PDF`, `DOCX`, `JPG`, `PNG`.
- فحص ذكي للمستندات متعددة الصفحات (Metadata Inspection, Page Count, Dimensions, DPI, Color/BW Detection).
- تحكم فردي وجماعي في مقاس الورق (A4, A5, A3)، وضع الطباعة (أبيض وأسود B&W، ألوان Color)، النسخ والاتجاه.
- دمج وإعادة ترتيب ومعاينة وتصدير PDF موحد جاهز للطباعة.

### 4. التوزيع الذكي للمقاسات المخصصة والمتعددة (Custom Size Layout)
- تحديد أي مقاس بالمليمتر (العرض × الارتفاع).
- خوارزمية تعبئة ثنائية الأبعاد (Guillotine / MaxRects 2D Bin Packing) لتوزيع مقاسات مختلفة ومتعددة النسخ على نفس الورقة بأقل هدر ممكن للورق.
- دعم مقاسات شهيرة جاهزة: 30×40، 40×50، 50×60، 60×90، 80×100 مم.
- تدوير تلقائي وتعديل يدوي بالماوس أو لوحة المفاتيح.
- تصدير PDF بجودة طباعة فيزيائية 300 DPI مع علامات القص.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: .NET 10.0 (WPF) - C# 13
- **Architecture**: MVVM (CommunityToolkit.Mvvm)
- **Computer Vision & Image Processing**: OpenCvSharp4
- **PDF Generation**: PDFsharp Core
- **Testing**: xUnit with 57 comprehensive unit and integration tests

## 🚀 تشغيل البرنامج (How to Run)

### المتطلبات:
- نظام Windows 10 أو 11
- .NET 10.0 SDK أو Runtime

### التشغيل المباشر:
- اضغط مرتين على `تشغيل_البرنامج.bat`.
- أو من خلال سطر الأوامر:
  ```bash
  dotnet run --project IdCardPrintShop/IdCardPrintShop.csproj
  ```

### تشغيل الاختبارات:
```bash
dotnet test
```
